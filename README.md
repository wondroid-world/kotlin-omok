# kotlin-omok

- 오목판은 15 * 15 줄이다.
- 5칸 연속 같은 색깔의 돌이 있는 상태

- 오목 게임을 시작합니다.
- 흑돌 먼저 턴을 가집니다.
- 흑돌의 위치를 입력받습니다.
- 흑돌의 위치를 오목판에 표시합니다.
- 백돌이 그 다음 턴을 가집니다.
- 백돌의 위치를 입력받습니다.
- 백돌이 놓는 자리에 흑돌이 위치하는 지 확인합니다.
- 흑돌이 놓는 자리면 다시 입력을 받습니다.
- 흑돌이 놓은 자리가 아니라면, 백돌을 오목판에 표시합니다.
- 흑돌 차례가 5번째가 되면, 오목인지 아닌지 판별을 시작합니다.
- 만약 오목이라면, 흑돌의 상태를 오목으로 판별합니다.
